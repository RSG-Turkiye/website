**Presenter**

**Batuhan Çakır**

**Abstract**

Omics is the general name for comprehensive approaches to profiling living systems. In single-cell studies, clustering is the most fundamental step: it lets researchers identify cell types from how cells group in reduced-dimensional space.

This talk examines web-based interactive visualisation platforms for single-cell data, comparing them on usability, user interface, developer support and performance with different file sizes, and comparing the file formats they use. The comparison is aimed at detailed single-cell analysis: identifying cell types, comparing gene expression between clusters, and exploring a dataset more broadly.

The talk was given in Turkish.
