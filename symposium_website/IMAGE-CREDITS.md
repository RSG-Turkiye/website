# Image credits

Not under `public/`, deliberately: everything there is served, so a
provenance note placed beside an image becomes a page. This is a
repository record.

## `public/images/metu-campus.jpg`

Photographed by a member of RSG-Türkiye and given to the organisers for use
on this site. Cleared by Emre Çevik on 2026-09-10, who knows who took it.

**No name here on purpose.** Two people have now been named in connection
with this one photograph and both times it had to be undone -- once because
the credit was wrong, once because the photographer did not want it. The
organisers know whose it is; this file does not need to, and the repository
is public.

The caption calls it the METU campus rather than the U3 amphitheatre. It
was offered as a picture of the hall and may well be one -- three brick
volumes under copper roofs is what a triple amphitheatre should look like
-- but nobody has confirmed which building it is. "Campus" is true either
way, and the photographer is the one person who could settle it.

`venue.photoCaption` in `src/i18n/ui.ts` is the string to change, in both
languages, if the building is identified or the photograph is replaced.
